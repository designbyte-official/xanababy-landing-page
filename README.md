# Xanababy Reimagined

A modern, scientifically-backed landing page for Xanababy, focusing on infant sleep solutions.

## Redesigned by DesignByte Studio

This project has been reimagined and developed by [DesignByte Studio](https://studio.designbyte.dev).

## Features

-   **Modern UI/UX**: Clean, responsive design built with React and Tailwind CSS.
-   **Dark Mode**: Fully supported dark mode with semantic color variables.
-   **Performance**: Optimized for speed and accessibility.
-   **Animations**: Smooth transitions using Framer Motion.

## Tech Stack

-   React
-   TypeScript
-   Tailwind CSS
-   Framer Motion
-   Vite

## Run Locally

1.  Install dependencies:
    ```bash
    pnpm install
    ```

2.  Run the development server:
    ```bash
    pnpm run dev
    ```

3.  Build for production:
    ```bash
    pnpm build
    ```
